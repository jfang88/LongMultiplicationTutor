🧠 How NSW learners build understanding

This tutor uses three connected representations. Each shows the same multiplication in a different way.

  • Area model: split numbers into hundreds, tens and ones.
  • Expanded multiplication: combine partial products using the distributive property.
  • Written algorithm: work column by column, recording carries and the tens shift.

Questions to ask your child

  • What does each digit really mean?
  • Why does the tens row start with a zero?
  • Which way would you check your result?
  • Can you explain the same answer another way?
