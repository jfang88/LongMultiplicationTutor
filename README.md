# Long Multiplication Lab

A free, child-friendly maths tutor for **3-digit × 2-digit** multiplication, structured around learning approaches used in NSW primary mathematics teaching: place value, area models, partial products and the formal vertical algorithm.

## Use it

Open [`index.html`](index.html) in any modern browser (works offline), or publish this repository to **GitHub Pages** from the `main` branch, `/ (root)`.

## Features

- Guided pathway: estimate → six-cell area model → expanded partial products → written algorithm with real carrying → explain the tens shift.
- Focused modes for practising area models, expanded multiplication, or the written method alone.
- Starter, practice and challenge question generators, with custom 3-digit × 2-digit input.
- Hints, step-by-step checking, carry boxes, place-value cues, rewards and responsive layout.
- No dependencies, account, tracking, network requests or external assets.

## NSW learning basis

Inspired by the **NSW Mathematics K–10 Syllabus (2022)** and NSW Department of Education guidance for multiplicative thinking. This is an *independent* teaching aid, not an official NSW Government product. It does not claim to reproduce any single school's mandated method.

- [NESA Mathematics K–10 syllabus](https://curriculum.nsw.edu.au/learning-areas/mathematics/mathematics-k-10-2022/overview)
- [NSW Department of Education: Numeracy skills for primary school](https://education.nsw.gov.au/teaching-and-learning/curriculum/literacy-and-numeracy/resources-for-parents-and-carers/numeracy-primary)
- [NSW Department of Education: Flexible multiplicative strategies – multi digit numbers](https://education.nsw.gov.au/teaching-and-learning/curriculum/literacy-and-numeracy/teaching-and-learning-resources/numeracy/multiplicative-thinking-multi-digit-numbers)

## GitHub Pages deployment

1. Create a public repo called `LongMultiplicationTutor` under `jfang88`, with `main` as its branch.
2. Upload `index.html` and `README.md` to the repo root.
3. In **Settings → Pages**, choose **Deploy from a branch**: `main`, `/ (root)`.
4. After GitHub Pages finishes publishing, open `https://jfang88.github.io/LongMultiplicationTutor/`.

**Publishing to GitHub Pages makes the website accessible to anyone.** No child data is transmitted by this app.
